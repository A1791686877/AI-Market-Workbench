# 产品需求文档（PRD）

## 1. 产品定义

“AI Market Workbench”是一个面向个人研究者和量化开发者的、可由人和 AI 读取同一份结构化市场事实的股票与加密货币分析平台。基础版只读，核心价值是可追溯的数据、确定性的指标、明确的数据完整性标签，以及不把模型意见伪装成确定结论的多情景分析。

产品不是券商、交易所、投顾、自动交易机器人或收益保证工具。第0阶段只交付设计；需求方确认前不创建业务代码。

## 2. 用户与核心任务

主要用户为单一研究用户：搜索任意美股或 BTC/ETH，查看同口径行情、指标和基本面，维护自选股，从高流动性约 500 只美股中发现需要进一步研究的候选，最后由用户主动点击“AI分析”生成可审计的多情景报告。

核心任务：

1. 搜索全部可用美股证券；默认扫描当日点时可得的高流动性 500 只普通股/ADR。
2. 分析 BTC、ETH 的指定交易所现货和 USDT 永续；所有交易所指标均标注 venue，不冒充全市场。
3. 在 15m、1h、4h、1d、1w、1mo 上查看同一引擎生成的价格、指标和证据；美股额外建议 195m。
4. 点击一次生成一次 AI 分析；行情刷新不触发模型费用。
5. 事后按 1h、4h、1d、1w 记录实际表现，用固定规则评估，而不把未来数据回填给历史分析。

## 3. 范围与非范围

### 3.1 基础版范围

- 美股：全部证券可搜索；默认扫描池仅含活跃普通股和 ADR，排除 ETF、基金、权证、优先股、units 和 OTC；自选股不受扫描池限制。
- 美股盘中：仅 America/New_York 的 09:30–16:00 正常交易时段，并遵循交易日历、DST、休市和提前收盘。
- 加密：BTC、ETH；指定 venue 的现货和 USDT 永续；24x7、UTC 分桶。
- 行情、财务三表、估值、公司行动、链上/衍生品指标、技术指标、结构化 AI 输出和审计记录。
- REST/OpenAPI、MCP 和 JSON Schema 共用一个领域服务。

### 3.2 明确不做

- 不连接真实交易账户，不接收账户 API key，不查询余额/持仓，不下单、撤单、转账或提币。
- 不抓取需要登录或绕过地域/反爬措施的数据。
- 不在基础版提供自动选股后的“买入/卖出”指令、自动化交易或盈利承诺。
- 不把截图识别值当成指标输入；不让 LLM 自行计算或猜测指标数值。
- 不一次性下载全体美股全部分钟历史，不把第三方原始数据公开再分发。
- 第一版不做新闻/社交情绪；若以后加入，外部文本必须按不可信输入隔离。

## 4. 功能需求

### 4.1 证券主数据与搜索

- 搜索键：ticker、公司名、CIK、交易所；返回证券类型、上市状态、主交易所、货币、数据可用范围和别名历史。
- ticker 不是永久主键。内部使用稳定 `instrument_id`，symbol change、并购、退市和重新上市形成带生效区间的映射。
- 每日收盘后按过去 60 个已完成交易日的 `median(raw_close × consolidated_volume)` 排名，生成下一交易日的 top-500；历史回测保存每日成分，禁止拿今天成分回看过去。
- 缺少完整市场成交量者不得进入默认 top-500，并记录排除原因；自选股仍可查看。

### 4.2 行情与周期

- 每根 bar 保存：open/high/low/close、volume、trade_count（可得时）、start/end、时区、session、是否最终、实际持续分钟、来源、接收时间、延迟、市场覆盖、数据质量。
- 美股同时保存 raw、split-adjusted、total-return-adjusted 三种口径；技术结构/FVG 默认 split-adjusted，执行相关价格水平同时展示对应 raw 值；长期收益可选 total-return-adjusted。
- 15m/1h 默认 2 年，4h 默认 5 年，日/周/月默认 20 年或最长；加密保存可靠来源允许的最长历史。
- 周/月只从已验证日线聚合；不得直接混用供应商周/月线。
- 未完成实时加密 bar 可显示为 preview，但不得生成 confirmed 信号；AI 默认仅使用已完成 bar。

### 4.3 扫描器

- 每个周期完成后运行确定性规则扫描；扫描规则版本化，输出候选而非交易建议。
- 第一期扫描维度：趋势、量价、RSI/MACD 状态、波动、确认背离、活动 FVG、支撑阻力距离、数据质量。
- 扫描结果必须包含规则命中证据、数据截止时间和排除理由；数据不完整、过期或隔离状态默认不排名。

### 4.4 指标与结构

- 支持 MACD、RSI、SMA、EMA、布林带、ATR、ADX、OBV、VWAP、成交量/量价、VPVR、支撑阻力、趋势结构、MACD/RSI 普通与隐藏背离、FVG。
- 所有指标返回统一 `IndicatorResult`：名称、算法版本、参数、输入口径、当前值、历史序列、状态、信号时间、锚点、确认状态、是否可能重绘、来源和证据。
- 默认参数、种子方法、空值和除零规则见 `06-INDICATORS.md`；参数变化写审计日志并生成新的参数集 ID。

### 4.5 基本面

- 美股：三表、收入/利润增长、FCF、capex、现金、债务、股份稀释、GAAP/非 GAAP、估值、盈利日期、SEC 申报、报告期、filed_at 和 source_updated_at。
- XBRL 值保留 taxonomy、tag、unit、period、form、accession 和 amendment；派生值记录公式与输入 fact IDs。
- 非 GAAP 不强行标准化为 GAAP；保留公司定义、调节项和来源段落。无法可靠抽取则为 `MISSING`。
- BTC/ETH：流通量、总供应量、市值、活跃地址等链上活动、网络费用/收入定义、venue 资金费率、OI、基差、可获得的清算和交易所净流入/流出。没有合格许可或定义时显示“缺失”。

### 4.6 AI 分析

- 仅用户点击后调用。按钮旁显示预计供应商、模型、快照截止时间和可能费用。
- 输出固定包含：看多、中性、看空情景；每种情景的前提、证据、关键水平和失效条件；数据冲突、缺失信息、置信度解释和非投资建议边界。
- 禁止只有“买入/卖出”；置信度不是盈利概率，除非未来用足够的样本外记录完成校准并清楚标注。
- 每次分析冻结输入快照和 SHA-256，保存参数集、提示词版本、供应商、模型、完整原始输出、结构化输出、token/费用、开始/结束时间。
- 后验评估写入独立 `analysis_outcome`；分析输入构建器在类型和查询层均不能读取该表。

### 4.7 页面

- 页首永久数据徽标：source、as_of、received_at、delay_class、coverage_scope、completeness、price_basis、timezone。
- 图表上区分 raw 与 adjusted；公司行动日显示标记；preview/partial bar 有不同样式。
- 每个指标可展开查看参数、公式、锚点和原始证据；缺失值显示“缺失（原因）”，不用 0 代替。
- AI 报告的每条证据都能回链到同一 snapshot 内的 bar/fact/indicator evidence ID。

## 5. 数据状态词典

- `COMPLETE`：在声明的来源和覆盖范围内通过连续性、重复、OHLC、成交量和时间检查。
- `PARTIAL`：来源本身采样、历史受限或 bar 实际时长短于目标。
- `STALE`：超过对应数据源 SLA/阈值。
- `MISSING`：预期字段无值；必须带 reason code。
- `QUARANTINED`：冲突或校验失败，不进入指标/AI。
- `FULL_SIP`：美股 CTA/UTP/SIP 口径的完整市场数据。
- `EXCHANGE_ONLY`：单个交易所；典型用于加密，不能写成“全市场”。
- `SAMPLED`：例如每秒只推一个清算快照；汇总值只能视为下限。
- `UNKNOWN`：供应商未作可核验声明；默认不用于依赖成交量的指标。

## 6. 非功能要求

- 可重复：相同数据快照、算法版本和参数必须产生 bitwise-stable 或在规定浮点误差内一致的结果。
- 因果性：任意时点 t 的 confirmed 输出在附加 t 之后数据后不得改变（prefix-invariance）。
- 安全：只允许已配置域名的 outbound；数据适配器无任意 URL；日志默认脱敏；前端从不接触供应商或模型密钥。
- 可观测：数据请求、切源、计算、AI、错误、参数、安全事件全部为结构化日志并带 trace ID。
- 存储：项目、数据、缓存、依赖、临时目录和日志全部显式指向 E 盘。基础版启动自检发现项目路径或配置路径指向 C 盘时 fail closed。
- 性能目标：缓存搜索 p95 < 300ms；缓存图表/指标 p95 < 2s；top-500 每个 15m 截止点后 5 分钟内完成；AI p95 仅作观测，不对第三方模型承诺 SLA。
- 可移植：Model Provider、Market Data Provider、Fundamental Provider、On-chain Provider 和未来 Exchange Adapter 均为接口，不在领域模型中泄露供应商字段。

## 7. 基础版验收标准

1. 任取 20 只美股、两个 DST 切换周、一个提前收盘日：盘前盘后成交量均不进入 bar 和所有指标。
2. 人工注入 2:1 split：raw 图出现价格阶跃，split-adjusted 技术序列连续，FVG 不生成，事件可追溯。
3. 15m/1h/4h/1d/1w/1mo 的边界、OHLCV 聚合与黄金数据一致；4h 第二根标记 150 分钟，提前收盘按实际时长。
4. IEX-only 或未知覆盖数据无法获得 `FULL_SIP` 标识，也不能进入完整成交量的 VWAP/OBV/VPVR 结论。
5. 每个指标通过黄金样例、性质测试、前缀因果测试和独立实现交叉验证。
6. FVG、背离只在所需右侧确认窗口结束后发出 confirmed 信号；在此之前标记 provisional。
7. AI 响应通过 JSON Schema；三种情景、冲突、缺失、失效条件和免责声明缺一则拒绝保存为成功。
8. snapshot 哈希重算一致；后验 outcome 表不存在通向提示词构建器的读取依赖。
9. 全仓库 secret scan 为零；网络测试证明没有私有账户、订单、转账或提币端点调用。
10. 进程级文件监控证明项目运行没有向 C 盘写项目数据；确属 Windows/驱动不可避免的系统写入须单列披露。
11. 锁定依赖生成 CycloneDX SBOM，许可证扫描通过，Critical/High 漏洞有修复或书面例外。
12. UI 和 API 对同一 snapshot 返回相同数值、参数、source、as_of 和 completeness。
