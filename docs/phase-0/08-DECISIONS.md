# 架构决策与进入开发前确认单

状态：Phase 0 有条件通过；四项业务决定已批准并进入 Phase 1

## 1. 已由需求锁定的边界

- 第一版严格只读：不连接真实账户，不申请/保存交易或提币权限，不提供下单、撤单、转账、账户查询工具。
- 不承诺盈利；AI 只输出看多/中性/看空条件情景、证据、失效条件、冲突、缺失与证据质量置信度。
- 页面与 AI 使用同一数据、指标和快照引擎；指标由确定性程序计算，模型不得从截图猜值。
- 美股技术分析只使用 09:30–16:00 ET 正常时段；加密统一 UTC 24×7 边界。
- 所有应用资产落在 `E:\AI-Market-Workbench`；不主动在 C 盘写项目数据。
- 当前阶段只交付设计文档，不创建业务代码。

## 2. 架构决策记录

### ADR-001：先采用模块化单体，而非微服务

**提议：采用。** API、采集、指标、快照和 AI Provider 保持严格模块边界；耗时任务由独立 worker 执行，共用 PostgreSQL/TimescaleDB 和对象式 Parquet 原始区。原因是第一版数据口径一致性、可追溯性和部署成本比独立扩缩容更重要。未来交易域必须另进程/另仓库/另权限，不属于该单体。

### ADR-002：Bronze/Silver/Gold 与不可变快照

**提议：采用。** Bronze 保存原始响应与哈希，Silver 保存标准化/复权/日历校验数据，Gold 保存指标与 AI 快照。任何更正都新增版本，不覆盖已被分析引用的快照。

### ADR-003：美股双源分工

**已批准的 Phase 1 覆盖。** Alpaca Basic 为盘中首选 adapter，Tiingo Free 为长历史日线首选，Massive Basic 为免费备用/交叉验证，SEC EDGAR 为申报真源。当前均先经过 fixture；需要账户关联凭据的 Alpaca 不在现有授权下启用。Massive Starter 与 Tiingo Power 暂不采购。源间差异进入隔离队列，不能静默择优；公开或商业部署必须另做授权评审。

### ADR-004：BTC/ETH 第一场所源

**提议：有条件采用 Binance 公共现货与 USD-M 数据。** 只调用无需密钥的公共行情；数据明确为 `VENUE_SPECIFIC_CRYPTO`。启用前检查所在地区可用性和当时条款，HTTP 451/限制时 fail closed，不使用代理规避。清算流标记 `SAMPLED/PARTIAL`，OI/基差有限历史从启用日起连续自存。备用交易所只通过同一只读 adapter 接入，换源形成新 source segment，绝不无标记拼接。

### ADR-005：股票 4 小时与补充周期

**提议：保留 4h，并增加 195m。** 4h 以 09:30 ET 锚定：09:30–13:30 为完整 4h，13:30–16:00 为 150 分钟不足柱，页面强提示。195m 在普通交易日恰为两根等长柱，最适合日内结构比较。2h 会形成 120/120/120/30 分钟，优先级低于 195m；仍可作为高级可选周期。

### ADR-006：价格口径

**提议：技术指标默认拆股复权，保存 raw/split-adjusted/total-return-adjusted 三套口径。** 图上涉及现实价格的支撑阻力同时给出原始价格映射。现金分红不伪装成自然缺口，FVG 默认排除行动窗口；估值使用点时股本和对应价格口径。

### ADR-007：周/月统一聚合

**提议：采用。** 周/月只从同一验证日 K、同一交易日历和同一复权版本聚合，不直接混用供应商周/月 K。供应商聚合仅用于质检。

### ADR-008：AI 调用与事后结果隔离

**提议：采用。** 仅用户点击时调用模型，先冻结 canonical JSON 快照和 SHA-256，再经可替换 Provider 输出 Schema。1h/4h/1d/1w 事后表现写入独立表和数据库角色；提示词构建账号无读取权限，从权限层阻断未来泄漏。

### ADR-009：开源组件边界

**提议：** Lightweight Charts 作为图表层；TA-Lib 仅作交叉验证；CCXT 只允许公共方法的薄封装。OpenBB/Qlib/Freqtrade 仅参考，RD-Agent/FinRobot/TradingAgents 不进入生产依赖。任何采用仍须在实现时固定提交/版本、构建 SBOM 并扫描锁定后的完整依赖树。

### ADR-010：缺失优先于推测

**提议：采用。** 缺少即显示 `MISSING` 和原因。未来盈利日期、全市场成交量、链上流入流出或清算全量性若未取得可靠授权/覆盖，禁止估算成事实。数据源失败也不得用不同口径静默替代。

## 3. 2026-09-05 已批准决定

1. **部署边界**：本地、单用户、个人研究；公开/多人/商业部署另做许可和架构评审。
2. **数据预算**：此前 USD 59/月只是可接受上限，Phase 1 实际预算已进一步冻结为 USD 0/月；Massive Starter 和 Tiingo Power 均不采购。先用 fixture 和免费层形成运行证据。
3. **周期设计**：195m 为美股 RTH 默认等长大周期；4h 保留并标记 150 分钟非完整尾柱；2h 非默认。
4. **加密首源**：Binance 仅作无密钥、公共、只读场所源；不连接账户，不加入交易权限，地区或条款限制时 fail closed。

## 4. 确认后仍然不自动获得的授权

批准 Phase 1 只代表允许创建只读项目代码与本地基础设施，不代表允许：

- 注册/登录供应商或替用户购买订阅；
- 输入、读取或迁移任何真实交易所账户凭据；
- 申请交易、合约、转账、提币权限；
- 发起订单或模拟成真实订单；
- 将个人授权数据公开、分享或商业再分发；
- 开启未来交易模块或改变盈利评估门槛。

这些事项若将来需要，必须分别取得明确授权与对应验收证据。
